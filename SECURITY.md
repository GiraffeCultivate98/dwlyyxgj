## 🛠 Troubleshooting

### Redshift not rendering

```powershell
# Update GPU driver
# NVIDIA: Download from nvidia.com/drivers (Studio Driver recommended)

# Check GPU compatibility
# Redshift requires NVIDIA RTX/GTX (CUDA) or AMD Radeon (requires separate installation)

# Reset Redshift preferences
Remove-Item "$env:APPDATA\Maxon\Redshift" -Recurse -Force
```

### Viewport lag with heavy scenes

```powershell
# Reduce viewport quality
# Display > Gouraud Shading (not Enhanced OpenGL)

# Use Level of Detail
# Object Manager > Right-click object > Cinema 4D Tags > LOD

# Enable viewport rendering limits
# Edit > Preferences > Viewport > Maximum visible objects = 10000
```

### Export to After Effects fails

```powershell
# Install Cineware plugin
# C:\Program Files\Adobe\Adobe After Effects 2024\Support Files\Plug-ins\Cineware.aex

# Update After Effects
# Help > Updates

# Export as .c4d file
# File > Export > Cinema 4D (not FBX)
```
